# AI-Loop and ICODA

Two independent applications in one repository. They share nothing but this folder and the licence.

- [`ai-loop/`](ai-loop/README.md) — AI-Loop: a persistent, resumable job runner that drives coding-agent CLIs
  unattended, with a Tkinter GUI, job database, Redis queues and e-mail control.
- [`icoda/`](icoda/EVOLUTION.md) — ICODA: Interactive Code Development and Analysis, a step-by-step,
  developer-in-the-loop code development tool with a live architecture view. Design in `EVOLUTION.md`, build plan in
  `ICODA_PLAN.md`.

Private files that belong to neither (the AI-Loop e-mail configuration, job worktrees under `ai-runs/`) live beside
this repository folder, not inside it.
